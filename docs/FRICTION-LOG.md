# Friction log — what Arc did that the docs did not say, as it happened

Build day 1, 2026-09-18, against `https://rpc.mainnet.arc.io` (chain 5042) and `https://explorer.arc.io`.

| # | What | Measured | Consequence in this repo |
|---|---|---|---|
| 1 | Anonymous RPC + CORS | `OPTIONS` and `POST` with `Origin: https://edycutjong.github.io` both answer with `access-control-allow-origin` echoing the origin. The docs' "permissioned" wording did not apply. | The page talks to the RPC directly from GitHub Pages; there is no proxy and no fallback if this changes. |
| 2 | `eth_getLogs` span | 10,000 blocks inclusive (`toBlock − fromBlock = 9,999`) answers; 10,001 → `-32012 requested range too large`. Five wide queries in a burst → `-32005 rate limit exceeded`. | `src/lib/scan.ts`: ≤ 9,000-block windows, one request at a time, 8 windows on open, more only on request, never past the order's `createdBlock`. |
| 3 | Explorer `/api` | Cloudflare "Just a moment…" challenge for a plain HTTPS client; the HTML pages render logged-out (HTTP 200). | Source verification through the API was not attempted from a script. The proof of what runs is the runtime-bytecode check in `scripts/preflight.py --bytecode` (on-chain code == `forge build` output with the immutable filled in). |
| 4 | `tx.gasprice` vs receipt `effectiveGasPrice` | Identical on every run so far (calibration ×3, seed ×3, incl. the 30 Gwei `capped` run where the contract saw 30 Gwei and capped itself to 20). | The contract's own price is the receipt's price; `npm run recheck` re-checks it on every committed row. |
| 5 | Metering drift | Calibration contract (`OVERHEAD = 31,400`): receipt `gasUsed` 58,030 vs metered 56,927 on three runs — a constant 1,103 gas, spread 0. Production contract (`OVERHEAD = 32,503`): drift 0, −6 (paused branch), 0. | One immutable absorbs it. The paused branch over-meters by 6 gas (the `if (!paid)` jump taken and the `paid = 0` word), i.e. the executor is over-refunded by 120 Gwei ≈ $0.00000012 on a refused payment. Left as is; inside the ≤ 50-gas gate. |
| 6 | Base fee | `baseFeePerGas` exactly 20,000,000,000 on every block touched today; `eth_gasPrice` ≈ 20.19 Gwei. | `2 × basefee` = 40 Gwei cap never bound for honest executors; scripts and page send priority 0 with `maxFeePerGas = max(eth_gasPrice, 20 Gwei)`. |
| 7 | Decimals | `msg.value` and balances are 18-decimal; the explorer shows 6-decimal USDC. `0.02 USDC` is `20000000000000000` wei on the wire. | Every amount in the repo is native wei; the page shows both. Never the ERC-20 view for native movements. |
| 8 | Gas fee not logged | The receipt's two system-emitter `Transfer` logs are the payee leg and the executor leg; the fee itself is not a log. | "Real fee" on the page = `gasUsed × effectiveGasPrice` from the receipt, shown *beside* the contract's refund, never asserted by it. |
| 9 | Foundry ergonomics | `forge create ... --constructor-args 31400` must come **last** (it swallows following flags and then dials `localhost:8545`); `cast wallet decrypt-keystore` takes `--keystore-dir` + `CAST_UNSAFE_PASSWORD`, not `--password-file`. | `scripts/lib/env.ts` passes the password through the environment of a child process; nothing key-shaped is ever printed. |
| 10 | Block rate | 1,058 blocks in 539 s at 10:44 UTC → 1.96 blocks/s (the 09-17 → 09-18 measurement said 1.97). | 8 windows × 9,000 blocks ≈ 10 h of history on open. |
| 11 | Costs at 20 Gwei | deploy 984,847 gas (0.0197 USDC) · create 122–140k (0.0024–0.0028) · execute 58,030 (0.00116) · execute-with-refusal 60,180 · cancel 40,536 · Rejector deploy 55,209. | The `live` order's tip (0.01) is ≈ 8.6× the gas of a run. |
