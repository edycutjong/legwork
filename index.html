Live on Arc mainnet · chain 5042 · 107 committed receipts

Standing USDC orders anyone can run — repaid the exact gas, in the same dollar, in the same transaction.

A payer funds a recurring payment with native USDC. When it is due, anyone calls execute(): the contract pays the payee, meters the gas the call consumed and pays the executor that gas plus the payer’s tip — from the same deposit, in the same transaction. On Arc the gas is USDC, so the refund is arithmetic: no oracle, no keeper network, no server.
